# Pet Comic 项目设计

## 目标

Pet Comic 是一个本机运行的温馨宠物漫画工具：输入若干宠物图片，系统理解画面，选择有趣场景，生成九格漫画剧本，生成九张单格漫画，再合成为一张九宫格漫画。

第一版以浏览器作为入口，前端和后端分别运行。应用不包含账号系统；本机维护一份全局宠物档案列表，任务通过 `pet_id` 引用宠物。

## 用户流程

1. 在宠物档案页上传 1–3 张证件照，填写名字和性格。
2. 系统调用视觉模型提取结构化外观，再调用 Images API 生成透明背景角色卡。
3. 角色卡生成完成后，宠物档案变为 `ready`，可用于图片匹配和漫画参考图。
4. 在任务创建页上传宠物图片，也可以提供受限的 HTTP(S) URL；不支持 base64 输入。
5. 系统使用全部 `ready` 宠物档案的结构化外观文本理解图片并返回 `pet_id` 匹配结果。
6. 系统选择候选场景并生成九格剧本。
7. 每格使用剧本引用的宠物角色卡作为 Images API 参考图；无 `pet_id` 时使用该场景的原始图片。
8. 系统生成九张无字单格图，在本地叠加对白/旁白，再拼接为九宫格漫画。

## 领域对象

- `PetProfile`：本机长期维护的宠物档案，状态为 `draft`、`ready` 或 `disabled`。
- `CharacterCard`：从宠物证件照生成的透明背景参考图，支持多版本并维护当前版本。
- `PetImage`：任务输入的宠物图片。
- `ImageUnderstandingRecord`：一张输入图的外观、动作、环境、趣味线索和宠物匹配结果。
- `SceneCandidate`：从图片理解结果中提取的候选叙事场景。
- `ComicScript`：严格包含九个漫画格的剧本。
- `PanelArtifact`：某个漫画格的生成图及其文字图层。
- `GenerationTask`：一次从输入图片到最终九宫格漫画的任务。

## 工作流

```text
宠物建档：
上传证件照 → 提取外观 → 生成角色卡 → ready

漫画任务：
校验输入 → 规范化图片 → 并行图片理解
→ 选择场景并生成剧本 → 校验剧本 → 展开漫画格规格
→ 并行生成单格图 → 叠加文字图层 → 拼接九宫格 → 完成
```

场景选择和剧本在领域上独立保存，第一版由一次结构化模型调用产生。任务支持取消、继续、失败项重试和单格重试；第一版不支持剧本编辑。

## 模型与配置

- 视觉理解和文本生成统一使用 LangChain 调用 OpenAI Responses API。
- 图片生成使用项目自己的 Image Provider Adapter 调用官方 OpenAI SDK 的 Images API。
- 供应商、base URL、API key 和 `vision_model`、`script_model`、`image_model` 绑定保存在 SQLite，由设置页面管理。
- `/v1/models` 返回的模型目录只保存在当前进程内，支持手动刷新。
- 运行参数由代码默认值和 `.env` 提供；代码默认值优先级低于 `.env`。
- 每个 LangGraph 节点开始时从 `backend/prompts/` 读取当前提示词，同一节点内固定本次读取的版本。

## 产物和保留

每个任务独立保存输入、结构化结果、单格图片、最终九宫格和事件文件。任务支持移入回收区、恢复和永久删除；第一版不自动清理。

角色卡和任务产物保留历史版本，当前展示版本由数据库指针决定。重跑创建新的 `execution_id`，成功后切换当前产物指针。
